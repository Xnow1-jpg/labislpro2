# Geometric_lib
> Данный проект включает в себя математические формулы, то есть библиотека геометрических формул
## Функции реализованные в данном проекте
### Формулы для круга
- **Нахождение площади:**
 - **Пример функции:**
 `def area(r):`
    `return math.pi * r * r`
 > r - (int) радиус окружности

 > `area(r)` -> (int) площадь круга

 Чтобы получить число *pi* мы воспользовались библиотекой *math*, чтобы её подключить надо написать в самом начале проекта `import math`, отрезок кода `math.pi` даёт точное число *pi*.
 - **Пример вызова функции:**
 > Ввод: *3*. Вывод: *28*.

- **Нахождение длины окружности:**
 - **Пример функции:**
 `def perimeter(r):`
    `return 2 * math.pi * r`
 > r - (int) радиус окружности
 
 > `perimetr(r)` -> (int) длину окружности

 Чтобы получить число *pi* мы воспользовались библиотекой *math*, чтобы её подключить надо написать в самом начале проекта `import math`, отрезок кода `math.pi` даёт точное число *pi*.
 - **Пример вызова функции:**
 > Ввод: *4*. Вывод: *25*.

### Формулы для квадрата
- **Нахождение площади:**
 - **Пример функции:**
 `def area(a):`
    `return a * a`
 > a - (int) длина стороны квадрата

 > `area(a)` -> (int) пложадь квадрата

 - **Пример вызова функции:**
 > Ввод: *2*. Вывод: *4*.

- **Нахождение периметра:**
 - **Пример функции:**
 `def perimeter(a):`
    `return 4 * a`
 > a - (int) длина сстороны квадрата
 
 > `perimetr(a)` -> (int) периметр квадрата

 - **Пример вызова функции:**
> Ввод: *5*. Вывод: *20*

### Формулы для прямоугольника
- **Нахождение площади:**
 - **Пример функции:**
 `def area(a, b):`
    `return a * b`
 > a - (int) первая сторона прямоугольника

 > b - (int) вторая сторона прямоугольника

 > `area(a, b)` -> (int) площадь прямоугольника

 - **Пример вызова функции:**
 > Ввод: *2* *3* . Вывод: *6*.

- **Нахождение периметра:**
 - **Пример функции:**
 `def perimeter(a, b):`
    `return 2 * (a + b)`
 > a - (int) первая сторона прямоугольника

 > b - (int) вторая сторона прямоугольника

 > `perimetr(a, b)` -> (int) периметр прямоугольника

 - **Пример вызова функции:**
 > Ввод: *5* и *4*. Вывод: *18*

### Формулы для треугольника
- **Нахождение площади:**
 - **Пример функции:**
 `def area(a, h):`
    `return a * h / 2`
 > a - (int) длина основания треугольника

 > h - (int) высота, падающая на основание треугольника

 > `area(a, h)` -> (int) площадь треугольника

 - **Пример вызова функции:**
 > Ввод: *8* *9* . Вывод: *36*.

- **Нахождение периметра:**
 - **Пример функции:**
 `def perimeter(a, b, c):`
    `return 2 * (a + b, c)`
 > a - (int) первая сторона треугольника

 > b - (int) вторая сторона треугольника

 > c - (int) третья сторона треугольника

 > `perimeter(a, b, c)` -> (int) периметр треугольника

 - **Пример вызова функции:**
  > Ввод: *5* и *4* и *3*. Вывод: *12*
