# Geometric_lib
> Данный проект включает в себя математические формулы, то есть библиотека геометрических формул
## Функции реализованные в данном проекте
### Формулы для круга
- **Нахождение площади:**
 - **Пример функции:**
 `def area(r):`
    `return math.pi * r * r`
 Функция принимает число *r* - радиус окружности, возвращает число: площадь круга.
 Чтобы получить число *pi* мы воспользовались библиотекой *math*, чтобы её подключить надо написать в самом начале проекта `import math`, отрезок кода `math.pi` даёт точное число *pi*.
 - **Пример вызова функции:**
 Ввод: *3*. Вывод: *28.274333882308138*.
- **Нахождение длины окружности:**
 - **Пример функции:**
 `def perimeter(r):`
    `return 2 * math.pi * r`
 Функция принимает число *r* - радиус окружности, возвращает число: длину окружности круга.Чтобы получить число *pi* мы воспользовались библиотекой *math*, чтобы её подключить надо написать в самом начале проекта `import math`, отрезок кода `math.pi` даёт точное число *pi*.
 - **Пример вызова функции:**
 Ввод: *4*. Вывод: *25.132741228718345*.
### Формулы для квадрата
- **Нахождение площади:**
 - **Пример функции:**
 `def area(a):`
    `return a * a`
 Функция принимает число *a* - длину стороны квадрата, возвращает число: площадь квадрата.
 - **Пример вызова функции:**
 Ввод: *2*. Вывод: *4*.
- **Нахождение периметра:**
 - **Пример функции:**
 `def perimeter(a):`
    `return 4 * a`
 Функция принимает число *a* - длину стороны квадрата, возвращает число: периметр квадрата
 - **Пример вызова функции:**
  Ввод: *5*. Вывод: *20*
### Формулы для прямоугольника
- **Нахождение площади:**
 - **Пример функции:**
 `def area(a, b):`
    `return a * b`
 Функция принимает число *a* и число *b* - длины сторон прямоугольника, возвращает число: площадь прямоугольника.
 - **Пример вызова функции:**
 Ввод: *2* *3* . Вывод: *6*.
- **Нахождение периметра:**
 - **Пример функции:**
 `def perimeter(a, b):`
    `return 2 * (a + b)`
 Функция принимает число *a* и *b* - длины сторон прямоугольника, возвращает число: периметр прямоугольника
 - **Пример вызова функции:**
  Ввод: *5* и *4*. Вывод: *18*
### Формулы для треугольника
- **Нахождение площади:**
 - **Пример функции:**
 `def area(a, h):`
    `return a * h / 2`
 Функция принимает число *a* - основание треугольника и число *h* - высота треугольника, возвращает число: площадь треугольника.
 - **Пример вызова функции:**
 Ввод: *8* *9* . Вывод: *36*.
- **Нахождение периметра:**
 - **Пример функции:**
 `def perimeter(a, b, c):`
    `return 2 * (a + b, c)`
 Функция принимает число *a* и *b* и *c* - длины сторон треугольника, возвращает число: периметр треугольника
 - **Пример вызова функции:**
  Ввод: *5* и *4* и *3*. Вывод: *12*
